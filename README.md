# Инфо
---
Для работы бота необходимо создать общедоступный канал-ловушку. Ставить его необходимо выше всех остальных каналов. Таким образом, боты-спамеры первым делом напишут туда и бот на это затриггерится и выдаст сразу тайм-аут с удалением сообщения (15 минут по умолчанию).

Также отдельно выдать боту права на тайм-аут, поскольку дискорд автоматически не может их выдавать.

Данного бота можно юзать на нескольких серверах. Инфа о серверах хранится на диске в файле ```guilds.json```

```/set-trap``` - позволяет выбрать канал-ловушка
```/remove-trap``` - удаляет канал-ловушку (не с сервера, а перестает триггериться на сообщения в этом канале)
```/set-timeout``` - можно изменить время таймаута, который выдает бот (в минутах)

# Запуск бота
---
Собрать образ для докера
```bash
docker build -t bot .
```

Запустить бота
```bash
docker run -d --restart unless-stoped bot
```
