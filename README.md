Для работы бота необходимо создан общедоступный канал-ловушку. Ставить его необходимо выше всех остальных каналов. Таким образом, боты-спамеры первым делом напишут туда и бот на это затриггерится и выдаст сразу таймаут.

Данного бота можно юзать на нескольких серверах. Инфа о серверах хранится на диске в файле ```guilds.json```
